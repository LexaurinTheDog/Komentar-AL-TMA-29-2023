# Komentar i ligjit nr. 29/2023 “Për tatimin mbi të ardhurat”

Komentar i një akti ligjor shqiptar: **ligji nr. 29/2023, datë 30.3.2023, “Për tatimin mbi të ardhurat”** (Fletorja Zyrtare nr. 70, 2023), i ndryshuar. Komentari përfshin **72 njësi** (nene) në 3 kapituj komentari; për çdo nen jepet teksti i plotë i dispozitës dhe komentari.
